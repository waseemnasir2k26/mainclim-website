# mainclim-website

Website for Main Clim, an HVAC (air conditioning, ventilation, refrigeration) company in Benin, in French. Includes three landing variants, services, about, projects with filters, contact, a multi-step quote request, a blog section, a WhatsApp chat button and a cookie banner.

Live: https://mainclim-website.vercel.app

## Stack

Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, React Hook Form with Zod, Lucide React. A CI workflow is in `.github/workflows/ci.yml`.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

Google Analytics is a placeholder until you add your own ID.
